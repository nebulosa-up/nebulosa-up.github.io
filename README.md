# Nebulosa Up - Soluções Inteligentes com IA

Site oficial da **Nebulosa Up**, uma iniciativa focada no desenvolvimento de aplicativos inteligentes que utilizam IA e análise de dados para facilitar a vida do usuário e potencializar resultados.

## O Projeto

Este repositório contém o código-fonte da nossa landing page, desenvolvida para apresentar nosso portfólio de aplicativos, com destaque para o **Super-Lotofacil**.

### Destaques do Site:
- **Design Moderno:** Interface "Glassmorphism" com modo escuro.
- **Responsividade:** Otimizado para dispositivos móveis e desktop.
- **Foco em IA:** Seções dedicadas a explicar como nossa tecnologia de Redes Neurais e Análise Preditiva funciona.

## Nossos Apps

### Super-Lotofacil
Nosso app principal que utiliza algoritmos de IA para analisar milhares de sorteios anteriores e gerar combinações com alta probabilidade estatística.

- **Status:** Disponível na Play Store
- **URL:** [Baixar na Play Store](https://play.google.com/store/apps/details?id=com.nebulosaup.superlotofacil.app&hl=pt_BR)

## Tecnologias Utilizadas
- HTML5
- Tailwind CSS
- Font Awesome
- Google Fonts (Inter)
